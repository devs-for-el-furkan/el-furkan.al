# El-Furkan.al

**Pitch:** An Albanian-language Quran website — read the Qur'an ayet-by-ayet in Arabic with Albanian translation, browse mushaf page scans, with tafsir/commentary coming.
**For:** Albanian-speaking Muslims reading/studying the Qur'an online — including readers who scan QR codes from a printed mushaf back to this site.
**Success:** Readers read Qur'an every day — searching, navigating, exploring new tafsir or related posts/books/lectures that use the ayahs, keeping track of hatme, reading the Arabic and following along with the Albanian translation, tracked via the ihsan.al app.

## Next milestone
Launch the MVP to production.

## Non-goals
- Only Albanian — no other translation languages
- No user comments
- No payments on this site — payments/pro features live only on ihsan.al

## Notes
Related-posts/tafsir content model already built in the shared `cms-ihsan-strapi` backend (tefsir + scholar content types, synced from QuranHub); not yet wired into this site's frontend — that's the milestone right after MVP launch.
